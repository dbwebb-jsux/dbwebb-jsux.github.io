## Knappar för att lägga till i varukorgen

Jag kommer i exemplet utgå från den produktlistningen som jag har i `index.html` och JavaScript koden i `main.js` som skriver ut den produktlistningen. I `main.js`-filen använder jag `map`-för att iterera över produkterna som jag har hämtat från API:t. Här lägger jag till ett `span` element med klassen `add-to-cart` och den specifika produktens id i ett `data-product-id`-attribut för att lägga till varor i varukorgen.

Produktmarkeringen nedan är ett exempel från min webbshop. Det enda som är nödvändigt är knappen (`span.add-to-cart`), lägg till den i din egen markup. Resten (`.bottom`, `<p>` osv.) behöver du inte kopiera.

```javascript
// main.js
products.map((product) => {
    return `<div class="product">
    <img src="${product.image_url}" alt="Album art ${product.name}" />
    <div class="bottom">
        <p>${product.name}</p>
        <span class="add-to-cart" data-product-id="${product.id}">+</span>
    </div>    
</div>`
  }).join("\n")
```

Jag skapar sedan filen `cart.css` som jag lägger till i `head`-elementet. Här lägger jag till CSS för att få en rund cirkel runt + tecknet som finns i `span`-elementet. Vi använder samma höjd och bredd, samt border-radius 50% för att skapa en rund cirkel, sedan använder vi flexbox för att centrera innehållet.

```css
/* cart.css */
.add-to-cart {
    display: flex;
    align-items: center;
    justify-content: center;
    background-color: var(--text-color);
    color: var(--background-color);
    border-radius: 50%;
    font-size: 2rem;
    width: 3ch;
    height: 3ch;
    cursor: pointer;
}
```

Vi skapar nu `cart.js` som kommer innehålla JavaScript-koden för vår varukorg. Du behöver inte lägga till `cart.js` i `head`, eftersom `main.js` importerar den (se nedan) och då laddas den bara en gång. Vi vill nu koppla en `eventListener` till de knapparna som vi precis skapade i `main.js`. Vi gör det genom funktionen `instantiateCartButtons` som vi sedan exporterar från filen.

```javascript
// cart.js
function instantiateCartButtons() {
  document.querySelectorAll(".add-to-cart").forEach(
    (elem) => elem.addEventListener("click", addToCart)
  )
}

function addToCart(event) {
  console.log(event.currentTarget.dataset.productId)
}

export { instantiateCartButtons }
```

Vi kan sedan i `main.js` importera och anropa funktionen efter att vi hämtat produkterna och lagt till produkterna och lägg-till-i-varukorgs-knappen i DOM-trädet.

```javascript
// main.js
import { instantiateCartButtons } from "./cart.js"
 
// Andra funktioner och kod

productList.innerHTML = products.map((product) => {
    return `<div class="product">
    <img src="${product.image_url}" alt="Album art ${product.name}" />
    <div class="bottom">

        <span class="add-to-cart" data-product-id="${product.id}">+</span>
    </div>    
</div>`
}).join("\n")

instantiateCartButtons()
```



### Själva varukorgshanteringen

Vi kan nu börja med att lägga till saker i varukorgen i funktionen `addToCart`, som anropas från `instantiateCartButtons`. Vi kommer som i kmom02 använda oss av LocalStorage för att hantera varukorgen. Vi kan bara spara ner strängar till LocalStorage, men vi använder oss av `JSON.parse`  och `JSON.stringify` ([Dokumentation](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON)) för att göra om objekt till strängar och omvänt.

Vi hämtar eller skapar först varukorgen utifrån LocalStorage eller ett tomt objekt. Sedan kollar vi om produkten redan finns i varukorgen och lägger då till ytterligare annars lägger vi till produkten i varukorgen. Vi avslutar med att göra objektet till en sträng igen och sedan sparar det i LocalStorage.

Vi använder `event.currentTarget` och inte `event.target`. `currentTarget` är elementet som vi kopplade lyssnaren till (knappen), medan `target` är det innersta element som klickades på, vilket kan vara ett barn till knappen, till exempel en ikon.

```javascript
// cart.js
function addToCart(event) {
  const productID = event.currentTarget.dataset.productId
  let cart = JSON.parse(localStorage.getItem("cart") || "{}")

  if (cart[productID]) {
    cart[productID] = cart[productID] + 1
  } else {
    cart[productID] = 1
  }

  localStorage.setItem("cart", JSON.stringify(cart))
}
```


### Visa varukorgen

Högst upp i `index.html` lägger jag i det elementet som jag vill ska innehålla min varukorg `.cart-content`. Jag lägger även till objektet `<div class="cart" id="cart">🛒</div>` som kan användas för att öppna och stänga varukorgen.

```html
<!-- index.html -->
<body class="site">
    <div class="cart-content" id="cart-content">
        <div class="cart-header">
            <h3>Inköpsvagn</h3>
            <p class="close-cart" id="close-cart">x</p>
        </div>

        <div class="cart-products" id="cart-products"></div>
    </div>
    <header class="header">
        <div class="inner-header">
            <h1><a href="index.html">Emil's skivor</a></h1>

            <div class="right">
                <a href="category.html">Kategori-sidan</a>

                <div class="cart" id="cart">🛒</div>

                <select id="mode" class="mode">
                    <option value="variables.css">Light</option>
                    <option value="variables-dark.css">Dark</option>
                </select>
            </div>            
        </div>        
    </header>

<!-- resten av koden -->
```

I filen `cart.css` lägger jag till följande CSS för att designa varukorgen. Jag använder `position: fixed;` för att lägga varukorgen utanför det normala flödet och fästa den mot webbläsarfönstret, så den ligger ovanför resten av sidan oavsett hur långt vi har scrollat. Bredden är `min(40rem, 100vw)`, så den är högst 40rem bred men aldrig bredare än skärmen (viktigt på mobiler). Just nu kan du inte se varukorgen men om du kommenterar ut `display: none;` bör den visas till höger på skärmen.

```css
/* cart.css */
.cart {
    font-size: 2rem;
    cursor: pointer;
}

.cart-content {
    display: none;
    position: fixed;
    top: 1vh;
    right: 0;
    height: 98vh;
    width: min(40rem, 100vw);
    background-color: var(--background-color);
    border-top-left-radius: 1.75rem;
    border-bottom-left-radius: 1.75rem;
    padding: 1.75rem;
    z-index: 1;
    box-shadow: -4px 4px 20px 0 rgba(0 0 0 / 75%);
    overflow-y: scroll;
}
```

Vi lägger även till selektorn `.cart-content.active` i `cart.css`. När vi har två klasser utan mellanrum i våra CSS-filer innebär det element som har båda klasserna.

```css
/* cart.css */
.cart-content.active {
    display: block;
}

body.cart-open {
    overflow: hidden;
}
```

Klassen `body.cart-open` används för att stoppa scrollningen av sidan bakom varukorgen. Vi sätter alltså klasser i JavaScript och låter CSS sköta utseendet, istället för att sätta inline-stilar.

Vi kan nu börja titta på logiken för att öppna och stänga varukorgen. Vi fortsätter med denna kod i `cart.js`. Först ser vi till att hämta ut de element som vi vill påverka och skapar sedan en `eventListener` för `cart`.

```javascript
// cart.js
const cartContent = document.getElementById("cart-content")
const cart = document.getElementById("cart")
cart.addEventListener("click", toggleCart)
```

I funktionen `toggleCart` togglar vi klassen `active` på varukorgselementet. När vi använder funktionen `toggle` läggs klassen till om den inte redan finns på elementet. Om klassen redan finns tas den bort. Vi sätter samma sak på `body` med klassen `cart-open`, vilket gör att vi inte kan scrolla på sidan när varukorgen är öppen. Är varukorgen öppen anropar vi även funktionen `renderCartProducts()` som renderar produkterna.

När man lägger till en produkt vill vi att varukorgen alltid ska vara öppen och uppdaterad, inte öppnas och stängas om vartannat klick. Därför har vi även en funktion `openCart` som alltid öppnar och renderar, och som `addToCart` använder.

```javascript
// cart.js
function toggleCart() {
  const isOpen = cartContent.classList.toggle("active")

  document.body.classList.toggle("cart-open", isOpen)

  if (isOpen) {
    renderCartProducts()
  }
}

function openCart() {
  cartContent.classList.add("active")
  document.body.classList.add("cart-open")
  renderCartProducts()
}
```

I `renderCartProducts()` hämtar vi ut vår varukorgsobjekt från LocalStorage och renderar ut varje produkt med det antal som ligger i varukorgen. Hela koden för `cart.js` ser alltså ut på detta sättet. Filen `models/products.js` använder vi för att hämta produkter från API:t, den visas strax efter listningen.

```javascript
// cart.js
import products from "../models/products.js"

const cartContent = document.getElementById("cart-content")
const cart = document.getElementById("cart")
cart.addEventListener("click", toggleCart)

const closeCart = document.getElementById("close-cart")
closeCart.addEventListener("click", toggleCart)

function toggleCart() {
  const isOpen = cartContent.classList.toggle("active")

  document.body.classList.toggle("cart-open", isOpen)

  if (isOpen) {
    renderCartProducts()
  }
}

function openCart() {
  cartContent.classList.add("active")
  document.body.classList.add("cart-open")
  renderCartProducts()
}

function instantiateCartButtons() {
  document.querySelectorAll(".add-to-cart").forEach(
    (elem) => elem.addEventListener("click", addToCart)
  )
}

function addToCart(event) {
  const productID = event.currentTarget.dataset.productId
  let cart = JSON.parse(localStorage.getItem("cart") || "{}")

  if (cart[productID]) {
    cart[productID] = cart[productID] + 1
  } else {
    cart[productID] = 1
  }

  localStorage.setItem("cart", JSON.stringify(cart))

  openCart()
}

async function renderCartProducts() {
  let cartHTML = "<p>No products in cart.</p>"
  if (localStorage.getItem("cart")) {
    const cart = JSON.parse(localStorage.getItem("cart"))
    const cartItems = []

    for (let product in cart) {
      const productInfo = await products.fetchProduct(product)
      const cartItem = `<div class="cart-item">
    <img src="${productInfo.image_url}" alt="Album art ${productInfo.name}" />
    <p>${productInfo.name}</p><p>Antal: ${cart[product]}</p>
</div>`

      cartItems.push(cartItem)
    }

    cartHTML = cartItems.join("\n")
  }

  document.getElementById("cart-products").innerHTML = cartHTML
}

export { instantiateCartButtons }
```


### models/products.js

Filen `models/products.js` hämtar produkter från Lager API:t med `auth` från [Lager API:t](/kunskap/lager_apit). API:t svarar med ett objekt där själva datan ligger under nyckeln `data`, så vi plockar ut den direkt i modulen. `fetchProduct` returnerar alltså själva produkten (`{ id, name, image_url, ... }`) och `fetchAll` en array med produkter.

```javascript
// models/products.js
import auth from "./auth.js"

const products = {
  fetchAll: async function fetchAll() {
    const response = await fetch(`${auth.api_url}/products?api_key=${auth.api_key}`)
    const result = await response.json()

    return result.data
  },

  fetchProduct: async function fetchProduct(id) {
    const response = await fetch(`${auth.api_url}/products/${id}?api_key=${auth.api_key}`)
    const result = await response.json()

    return result.data
  }
}

export default products
```

Använd samma form på `fetchProduct` i kommande övningar, då slipper du skriva `.data.name`, utan bara `product.name`.
