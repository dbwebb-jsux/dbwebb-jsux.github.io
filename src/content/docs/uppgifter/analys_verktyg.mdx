Du kommer genom kursen att ta ett analytiskt perspektiv på en verklig webbplats design utifrån temat från kursen: Att bygga en webbshop. I detta kursmoment tar vi ett lite mer tekniskt perspektiv.



## Skapa rapportfilen

Skapa en struktur för din rapport, det kommer fler sådana här uppgifter.

```bash
# Stå i kursrepot
touch reports/kmom05.md
```


## Rapportstruktur

När du skriver din rapport så kan du följa denna rubrikstruktur. Det är en struktur som är vanligt använd i rapportsammanhang (och i ditt kommande examensarbete).

```text
Titel på rapporten
=======================

Skriv en eller två rader om vad uppgiften handlar om.

Urval
-----------------------

Berätta vilken webbplats du valt att undersöka och varför eller hur du gick tillväga när du gjorde ditt urval.

Metod
-----------------------

Berätta kort om din "metod", hur du gör för att utföra undersökningen. Berätta om du använder något speciellt verktyg.

Resultat
-----------------------

Dokumentera dina resultat från din studie. Berätta vad du kom fram till, vilka resultat du hittade och observerade.

Denna veckan kan tre tabeller i markdown vara på sin plats.

| Webbsida 1    | Performance  | Accessibility     | Best Practices | SEO           |
|---------------|--------------|-------------------|----------------|---------------|
| Förstasidan   |              |                   |                |               |
| Produktsidan  |              |                   |                |               |
| Ordersida     |              |                   |                |               | 


| Webbsida 2    | Performance  | Accessibility     | Best Practices | SEO           |
|---------------|--------------|-------------------|----------------|---------------|
| Förstasidan   |              |                   |                |               |
| Produktsidan  |              |                   |                |               |
| Ordersida     |              |                   |                |               | 


| Webbsida 3    | Performance  | Accessibility     | Best Practices | SEO           |
|---------------|--------------|-------------------|----------------|---------------|
| Förstasidan   |              |                   |                |               |
| Produktsidan  |              |                   |                |               |
| Ordersida     |              |                   |                |               | 


Analys
-----------------------

Diskutera och analysera de resultaten du fann.

Referenser
-----------------------

Ange de eventuella referenser du använder dig av, om några.
```

Strukturen är inte absolut nödvändig, se den som en möjlighet att träna på god struktur av rapportskrivning.



Krav
-----------------------

1. Använd <HiddenPrompt />samma 3 webbshoppar som tidigare i kursen.

1. Utifrån <HiddenPrompt />dina valda webbshoppar ska vi analysera hur de presterar enligt Google Lighthouse.

1. Välj <HiddenPrompt />tre liknande enskilda sidor från dina webbshoppar, förslagsvis förstasidan, en produktsida och en ordersida/varukorgen.

1. Använd <HiddenPrompt />Google Lighthouse ([instruktion](/kunskap/google_lighthouse)) och kör en rapport med Desktop vald för var och en av de 3 sidorna. Kör i ett inkognitofönster, poängen varierar något mellan körningar så notera gärna ett typvärde efter att ha kört två eller tre gånger.

1. För <HiddenPrompt />varje sida för varje webbshop notera ner i tabellen.

1. Reflektera <HiddenPrompt />ur ett tekniskt perspektiv med utgångspunkt i de förbättringar ("insights") som Google Lighthouse föreslår hur webbplatserna kan förbättras.

1. Kör <HiddenPrompt />även Lighthouse på din egen webbshop (samma tre sidor, fyll i som en fjärde tabell) och jämför med de andra webbplatserna. Ger Lighthouse dig förslag som du kan åtgärda, till exempel bildstorlekar? Se artikeln [Responsiva bilder](/kunskap/responsiva-bilder).
