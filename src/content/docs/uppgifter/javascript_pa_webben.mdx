Vi kommer igenom kursen ta ett analytiskt perspektiv på en verklig webbplats design utifrån temat från kursen: Att bygga en webbshop. I detta kursmoment tar vi ett lite mer tekniskt perspektiv. Använd samma webbshop som i kmom01 och kmom02.



## Skapa rapportfilen

Skapa en struktur för din rapport, det kommer fler sådana här uppgifter.

## Rapportstruktur

När du skriver din rapport så kan du följa denna rubrikstruktur. Det är en struktur som är vanligt använd i rapportsammanhang (och i ditt kommande examensarbete).

```text
Titel på rapporten
=======================

Skriv en eller två rader om vad uppgiften handlar om.

Urval
-----------------------

Berätta vilken webbplats du valt att undersöka och varför eller hur du gick tillväga när du gjorde ditt urval.

Metod
-----------------------

Berätta kort om din "metod", hur du gör för att utföra undersökningen. Berätta om du använder något speciellt verktyg.

Resultat
-----------------------

Dokumentera dina resultat från din studie. Berätta vad du kom fram till, vilka resultat du hittade och observerade.

Denna veckan kan en tabell i markdown vara på sin plats.

|               | Antal filer  | Mängd JavaScript  | Laddningstid  |
|---------------|--------------|-------------------|---------------|
| Förstasidan   |              |                   |               |
| Produktsidan  |              |                   |               |
| Ordersida     |              |                   |               | 



Analys
-----------------------

Diskutera och analysera de resultaten du fann.

Referenser
-----------------------

Ange de eventuella referenser du använder dig av, om några.
```

Strukturen är inte absolut nödvändig, se den som en möjlighet att träna på god struktur av rapportskrivning.



Krav
-----------------------

1. Utifrån <HiddenPrompt />din valda webbshop ska vi analysera hur mycket JavaScript som laddas in och används på webbplatsen.

1. Välj <HiddenPrompt />tre enskilda sidor från din webbshop, förslagsvis förstasidan, en produktsida och en ordersida/varukorgen.

1. Använd <HiddenPrompt />Network-fliken i din webbläsare och ladda om sidan utan cache.

1. Filtrera <HiddenPrompt />ut så endast JavaScript filer visas, notera följande:
    1. Hur många JavaScript-filer laddas in på respektive sida?
    1. Hur stor mängd JavaScript laddas på respektive sida?
    1. Hur lång tid tar det att ladda de olika sidorna?

1. Vänta <HiddenPrompt />tills sidan har laddat klart innan du läser av siffrorna (sidor laddar ofta in fler skript efter en stund), och ha samma tillstånd för alla sidor. Acceptera till exempel cookie-samtycke på alla eller på ingen. Skriv i metoden vilket du valde.

1. Ange <HiddenPrompt />om storleken är "Transferred" (det som skickats över nätverket) eller "Resources" (storleken efter uppackning) i Network-fliken. Välj en av dem och använd den för alla sidor.

Siffrorna varierar mellan olika mätningar (A/B-tester, annonser, cache och cookie-banners), så mät gärna mer än en gång och skriv att resultaten är ungefärliga.
