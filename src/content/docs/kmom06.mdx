### Kurslitteratur

I kursen används [Designing interfaces: patterns for effective interaction design](https://go.exlibris.link/zrLb9rwc) skriven av Tidwell J, Brewer C, Valencia A som kurslitteratur. Boken är tillgänglig som e-bok via biblioteket.

Läs kapitlet "11. User Interface Systems and Atomic Design". Fokusera på hur ett användargränssnitt kan byggas upp av små, återanvändbara delar (atomer, molekyler, organismer) och vad ett designsystem är, det är samma tänk som vi använder när vi gör webbkomponenter.
